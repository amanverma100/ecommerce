# 🛒 E-Commerce Web App (MERN Stack)

A modern full-stack **E-Commerce platform** built using **MongoDB, Express, React, and Node.js**.  
It supports product browsing, detailed product view with zoom, category management, cart handling, and backend API integration.

---

## ⚙️ Features
- 🧾 Product listing and category management  
- 🔍 Product details with image zoom  
- 🛍️ Add-to-Cart and order flow  
- 🔐 Secure API using Express & MongoDB  
- ⚡ Modern UI built with React + TailwindCSS
